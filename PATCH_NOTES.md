# PolyPulse Community Beta → VORVEXON bridge patch

Этот патч не переименовывает PolyPulse и не меняет его бесплатные функции.
Он делает только три вещи:

1. Меняет блок в N-панели с ранним анонсом PolyPulse Pro на анонс VORVEXON.
2. Меняет кнопку на `Follow VORVEXON Development`.
3. Добавляет короткое объявление и Telegram-ссылку в английский и русский README.

## Как применить

Сделай резервную копию исходного аддона, затем замени только эти файлы:

- `__init__.py`
- `README.md`
- `docs/README.ru.md`

## Важно

Сейчас ссылка указана как `https://t.me/vorvexon`.
До упаковки следующей beta проверь, что этот username действительно закреплён за твоим каналом. Если итоговый username другой, замени URL во всех трёх файлах.

Старый опубликованный ZIP Community Beta можно не обновлять: этот патч предназначен только для следующей добровольной community-сборки.
